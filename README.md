# 新着出品監視ツール

メルカリ・ラクマ・2nd STREET・BOOKOFFをキーワードで定期検索し、
新着商品が出たらDiscordに通知します。

---

## あなたがやる作業

### ① Discordの通知先を作る(5分)
1. Discordで通知を受け取りたいサーバーを用意する(自分専用の個人サーバーを新規作成でOK)
2. 通知を受け取りたいテキストチャンネルの右クリック →「連携サービス」→「ウェブフック」
3. 「新しいウェブフック」を作成し、「ウェブフックURLをコピー」をクリック
4. コピーしたURLを `config.json` の `discord_webhook_url` に貼り付ける
   (GitHub Actionsで動かす場合は⑤で使うのでメモしておくだけでOK)

### ② キーワード・監視サイトを編集する
`config.json` を開いて以下を自分好みに変更:
- `keywords`: 探したいブランド名やキーワードのリスト
- `sites`: 監視したいサイトだけ `true`
- `max_price`: この価格を超える商品は通知しない(不要ならこの行を削除)

### ③ 動作テスト(自分のPCで)
```bash
pip install -r requirements.txt
python main.py
```
実行してエラーが出ないか、Discordに通知が届くか確認してください。

### ④ 自分のPCで定期実行する場合
- **Windows**: タスクスケジューラで「10〜15分ごとに `python main.py` を実行」するタスクを登録
- **Mac/Linux**: `crontab -e` で以下を追加(15分おきの例)
  ```
  */15 * * * * cd /path/to/monitor && /usr/bin/python3 main.py >> log.txt 2>&1
  ```
  PCがスリープ/シャットダウンしている間は動きません。

### ⑤ 無料のクラウドで常時動かす場合(おすすめ)
コストを抑えたいとのことなので、**GitHub Actions**(パブリックリポジトリなら無料)を使う方法です。

1. GitHubアカウントを作成(未所持の場合)
2. 新しいリポジトリを作成(Publicなら無料枠が実質無制限。中身はキーワードくらいなので公開されて困る情報はありません)
3. このフォルダの中身一式をそのリポジトリにアップロード(GitHubのWeb画面の「Add file → Upload files」でドラッグ&ドロップでOK)
4. リポジトリの `Settings → Secrets and variables → Actions → New repository secret` を開き、
   - Name: `DISCORD_WEBHOOK_URL`
   - Value: ①でコピーしたウェブフックURL
   を登録
5. `Actions` タブを開いて、ワークフローを有効化する(初回は確認ボタンを押す必要があります)
6. あとは20分おきに自動実行され、Discordに通知が届きます。スマホにDiscordアプリを入れて通知をONにしておけば、暇な時間に確認できます。

※ Privateリポジトリでも動きますが、無料枠(月2000分)を使い切らないよう実行間隔を30分以上にしてください。

## 大事な注意点

- これは**個人利用のための私的なツール**です。転売の自動購入(即決ボタンを自動で押す等)は行っていません。あくまで「新着を早く知る」ためのものです。
- 各サイトの利用規約でスクレイピングが制限されている場合があります。**アクセス頻度を上げすぎない**(20分おき程度を推奨)、**大量アカウントでの運用はしない**など、常識の範囲での利用をお願いします。
- LINE通知は2025年3月末で「LINE Notify」が終了しており、代替の「Messaging API」は公式アカウント開設など準備が煩雑なため、今回はスマホでも受け取りやすいDiscordのみ実装しています。LINEにどうしても通知したい場合は追って対応できます。

## サイトの構造が変わって動かなくなったら

各サイトはHTMLの構造が今後変わる可能性があります(実際にこのツールも「現時点でこう動くはず」という設計で、各サイトへの実アクセステストはしていません)。
`python main.py` を実行して特定のサイトだけ0件が続く、またはエラーが出る場合は、

1. ブラウザでそのサイトの検索結果ページを開く
2. 右クリック →「検証」→ 商品リンクの部分のHTMLをコピー

して私に見せてもらえれば、`scrapers.py` の該当箇所を修正します。
